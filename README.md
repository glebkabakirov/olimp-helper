# Олимп-хелпер

Android-приложение, которое следит за датами олимпиад по информатике: регистрации, отборочные и
заключительные этапы. Данные берутся из
[Google-таблицы](https://docs.google.com/spreadsheets/d/16wKSRx8b7BC8YQeT9ulPl3gHKJ7hHWq0/edit?gid=749938116),
а раз в 3 дня Claude проверяет сайты олимпиад и кладёт найденное в `data/updates.json` в ветке
[`claude/updates`](https://github.com/glebkabakirov/olimp-helper/blob/claude/updates/data/updates.json)
(облачный Claude может пушить только в ветки `claude/…`; в `main` этот файл остаётся пустым).

## Что умеет

- **Скоро:** события на ближайшие 14 дней (можно 7 или 30): открытие и конец регистрации, начало и конец
  этапа, дни туров. Ниже идут открытые регистрации, где ты ещё не отметился, и этапы, которые идут сейчас.
- **Позже:** всё, что дальше, по месяцам. Неточные даты помечены ≈, необъявленные собраны внизу.
- **Олимпиады:** карточка каждой олимпиады с исходным текстом из таблицы, ссылками и отметками.
- **Изменения:** что поменялось в таблице с прошлой синхронизации и что Claude нашёл на сайтах.
- Отметка **«Зарегистрировался»** убирает события регистрации этапа, сам этап остаётся.
- Отметка **«Прошёл дальше»** включает заключительный этап: до неё финал виден в «Позже» с пометкой
  «если пройдёшь», но не попадает в «Скоро» и не шлёт напоминаний.
- Напоминания утром после 9:00 за 3 дня, за 1 день и в день события. Отдельные уведомления приходят
  об изменениях в таблице и находках Claude.
- Таблица синхронизируется при открытии приложения и в фоне примерно раз в 6 часов. Без интернета
  показываются последние скачанные данные.

## Установка на телефон

1. Скачай `olimp-helper.apk` со страницы
   [последнего релиза](https://github.com/glebkabakirov/olimp-helper/releases/latest)
   (или перекинь файл на телефон любым способом).
2. Открой файл и разреши установку из этого источника, если Android спросит.
3. При первом запуске разреши уведомления.

Новая версия ставится поверх старой, отметки сохраняются.

## Как устроено

```
Google-таблица (xlsx) ──┐
                        ├─► приложение: разбор дат → события → вкладки и напоминания
updates.json ───────────┘
(ветка claude/updates)
        ▲
        └── Claude routine раз в 3 дня: сайты олимпиад → отличия от таблицы → force-push
```

- `app/src/main/java/ru/olimphelper/domain/` — разбор дат (`DateParser`), окна регистрации из примечаний
  (`Registration`), события (`EventBuilder`), раскладка по вкладкам (`Tabs`), сравнение таблиц (`TableDiff`).
- `app/src/main/java/ru/olimphelper/data/` — чтение xlsx со ссылками, хранилище и синхронизация.
- `app/src/main/java/ru/olimphelper/work/` — фоновая синхронизация и уведомления (WorkManager).
- `routine/PROMPT.md` — инструкция для Claude, `routine/read_table.py` — чтение таблицы со ссылками.

Приложение всегда показывает исходный текст ячейки рядом с разобранной датой, поэтому ошибку разбора
сразу видно.

## Сборка

Нужны JDK 17 и Android SDK (platform 35). Путь к SDK указывается в `local.properties`.

```bash
./gradlew test             # тесты разбора на снимке настоящей таблицы
./gradlew assembleRelease  # app/build/outputs/apk/release/app-release.apk
```

Подпись релиза берётся из `keystore.properties` (в git не попадает): `storeFile`, `storePassword`,
`keyAlias`, `keyPassword`. Без этого файла релиз подписывается debug-ключом.
